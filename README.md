# Threads at Risk — Digital Textile Archive

A colourful, searchable digital archive of traditional Indian textile practices. The site includes textile records, image galleries, a state-based explorer, source notes, and archive credits.

## Preview locally

1. Extract the ZIP folder.
2. Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, this README, and the complete `images` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site and open the generated URL.

## State explorer note

The state explorer is a schematic navigation map with clickable state markers, not a survey-grade or administrative boundary map. The textile associations shown for each state are drawn from the place/origin information in the archive metadata. A state with no matching record is identified as having no entry in the current archive.

## Images and metadata

All image files supplied with the project ZIP are included in the `images` folder. Textile descriptions and metadata fields are retained in each record. Image credit and source notes are shown within the corresponding textile record.
